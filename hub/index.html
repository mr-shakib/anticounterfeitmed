What this service does. It checks whether a code on a medicine strip matches a record its manufacturer signed, using ML-DSA (FIPS 204) post-quantum signatures.

What it does not do. It does not test the contents of the medicine, and a successful check is not proof that a package is genuine or safe to take.

A research project of RDG–ICSETEP, Daffodil International University.
