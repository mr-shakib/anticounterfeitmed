# Brand assets

`mark.webp` is the project mark, carried over from the public site so that the
app, the portal and the landing page show the same badge a visitor already
associates with the project.

Derived files are generated by `scripts/build_brand_assets.py` rather than
committed by hand, so every surface stays in step when the mark changes:

| Output | Used by |
| --- | --- |
| `landing/mark.png` | the public landing page header |
| `landing/favicon.png` | the landing page tab icon |
| `staff-web/public/mark.png` | the portal sidebar and sign-in screen |
| `staff-web/app/icon.png` | the portal tab icon |
| `consumer-app/assets/brand/mark.png` | the app's own screens |
| `consumer-app/android/app/src/main/res/mipmap-*/ic_launcher.png` | the Android launcher icon |

Run `make brand` after replacing `mark.webp`.
